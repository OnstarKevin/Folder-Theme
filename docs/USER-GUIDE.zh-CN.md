# 文件夹主题工坊使用教程

当前版本preview8：插件页一键体验“专注与日程”，设置专注/休息和每日提醒；设计页“内置精选图标”提供五款图片。AI提示词先作为上下文发送，等待AI询问后再发需求。

历史版本 `FolderThemeStudio-v0.1.0-beta.24-preview.7-setup.exe`：主窗口左侧“插件”直接进入卡片管理页；左侧“设置”打开大卡片，选择功能并通过“返回全部设置”返回。插件声明式设置沿用Preview6。




## Beta 24 Preview 3：背景、指标与音乐

安装 `FolderThemeStudio-v0.1.0-beta.24-preview.3-setup.exe`。CPU和内存开关在“设置 → 灵动岛”，开启后常显于主岛右侧。背景、选图和细边框在“设置 → 外观与字体”；选图后调节渐变方向/方式/强度/起点、淡色与透明度，保存应用。推荐1200×160px横图、2MiB以内，导入最大16MiB，自动缩小并保存私有副本。播放音乐时岛会弹簧变形，悬停可上一首/播放暂停/下一首，查看歌词、进度、来源与性能。播放器需支持Windows媒体会话与对应控制。

## Beta 24 模块化设置试用

安装 `FolderThemeStudio-v0.1.0-beta.24-preview.2-setup.exe`。主窗口“设置”进入模块工作区，左侧直达常规、功能开关、灵动岛、外观与字体、歌词与播放器、消息与剪贴板和插件。切换模块保留未保存草稿；保存原位应用，“放弃修改”恢复上次保存的设置（同一配置下的各模块草稿一并恢复）。插件操作立即生效，权限在页面内确认。托盘设置和灵动岛右键设置均打开这个工作区。“灵动岛”页可显示、关闭或编辑位置。原文件选择器保留，用于字体、LRC文件夹、插件包和SDK导出。

## Beta 24 外观试用

安装 `FolderThemeStudio-v0.1.0-beta.24-preview.1-setup.exe`。在托盘“灵动岛设置与插件 → 外观与动画”选择字体：默认微软雅黑粗体，支持导入TTF/OTF/TTC（最大32MiB）、选择字族、预览、恢复默认，保存后生效。导入会保存私有副本，不安装系统字体；重启保留选择，失效回退微软雅黑。本版恢复原图片背景，高度36.4 DIP，仍为单行。以下为Beta23通用说明；其默认全透明描述被本节取代。

## 安装与启动

1. 运行 `FolderThemeStudio-v0.1.0-beta.23-setup.exe`。
2. 若电脑缺少 .NET 8 桌面运行时，请保持联网，让安装器自动安装。
3. 首页整合桌面灵动岛、图标设计、活文件夹、自动样式与备份恢复。左侧底部可打开“使用教程”和“设置”；语言切换位于设置中。

## 桌面灵动岛（Beta 23）

灵动岛默认全透明背景、单行且点击穿透；鼠标操作交给后面的窗口。悬停约650毫秒显示精简摘要卡，也可在设置中关闭。深色壁纸可选择浅色文字。

通过托盘“灵动岛设置与插件”打开设置，通过“编辑灵动岛位置”拖动；Esc、右键完成编辑或30秒后恢复穿透。文字透明度、伸缩动画、吸附和数据模块均可独立调整。

设置 → 插件与DIY：一键安装或拖入.islandpkg、安装专注示例、独立启停/移除。AI提示词默认折叠，展开后复制给AI即可开发；完整协议可在开发者面板中导出；源码中位于 plugins-sdk/README.zh-CN.md。涉及音乐、剪贴板、通知的数据权限需授权，对应模块也须开启。首版无网络、系统命令和DLL接口。

播放中的音乐/歌词、短暂剪贴板和新消息按优先级显示；DIY内容高于空闲金句。在线歌词默认关闭，开启后发送歌名和歌手；本地LRC优先。Windows通知需要对应授权，并不读取所有应用的自绘聊天弹窗。

Beta23已移除双层桌面，升级会恢复旧启用配置的图标状态。异常时仍可运行 `FolderThemeStudio.App.exe --restore-desktop` 显式恢复。

## 三步开始使用

1. 从首页点击“开始设计”，选择内置的 12 组苹果风格色块和文件夹材质，或导入自己的图片。高级参数默认折叠；需要时可展开调整渐变、描边和光晕。
2. 点击“添加文件夹”，选择要应用的目录。默认只更改所选文件夹；也可切换为当前用户的全部普通文件夹。
3. 点击“计算方案”，检查预览后点击“应用”。无需保存个人主题；“我的样式”中的保存仅用于以后复用。需要撤销时从首页进入“备份与恢复”。

## 材质、贴纸与模拟桌面

使用内置文件夹样式时，可选择柔光、玻璃、黏土、磨砂玻璃和纸张材质；在折叠的“贴纸装饰”中选择图案、颜色、大小和角度，并在大图上拖动贴纸。“检查浅色、深色与不同尺寸”及“模拟桌面”可展开，检查细节和整体效果。模拟桌面选项只影响预览。

## 导入图片图标


1. 在“图标来源”中选择“导入图片图标”。
2. 点击“选择图片”，导入 PNG、JPG、JPEG、BMP 或 ICO；不支持 GIF。多尺寸 ICO 会自动采用最大分辨率图层。
3. 图片会作为完整图标使用，并自动保持比例、居中和补透明边距。
4. 确认预览后计算方案并应用。
5. 刚导入的图片或 ICO 会立即成为当前图标，不需要额外保存。

## 活文件夹

将鼠标停在普通桌面或资源管理器文件夹上约半秒，卡片会显示该文件夹最近修改的五个普通文件。拖动普通文件到卡片后，将其放到“此文件夹”或直属子文件夹行上即可移动。为避免误操作，文件夹本身、符号链接和已有同名文件不会被移动或覆盖。

卡片同时显示创建和修改时间、直属内容数量与含子目录的大小摘要。识别到文件夹后，软件会临时收起该窗口对应的 Windows 信息提示；离开或原生点击后解除，不修改系统全局偏好。目录较大、部分内容不可读或包含链接时显示“部分统计”。

## 应用与恢复


- 全局模式统一修改当前用户的普通文件夹图标映射，不扫描整个磁盘。
- 兼容模式仅处理手动添加的根目录；已有自定义配置会安全合并，特殊、受保护或不可写文件夹仍会跳过。
- 勾选“让新文件夹继续使用此样式”后，软件会递归监控所选根目录，新建文件夹自动继承当前图标。
- 从首页或左侧打开“自动样式规则”，为已监控目录添加名称关键词与图标；可选当前编辑样式，也可导入图片或 ICO。
- 名称按“不区分大小写的包含匹配”判断；列表越靠前优先级越高。没有匹配时使用该根目录原有的监控图标。
- 规则递归覆盖所选根目录下之后新建的文件夹；重命名事件仍使用原有默认图标处理，不会批量改写已有文件夹。
- 从首页或左侧打开“文件夹分类卡片”，选择普通文件夹并填写分类、备注和强调色后保存；也可直接选择苹果风格色块。
- 默认在目标文件夹上按 Alt＋鼠标右键打开精简备注窗口。路径自动绑定点击的文件夹，直接输入备注即可；Ctrl＋Enter 保存并关闭，Esc 取消。分类与颜色在折叠选项中。设置中可调整组合键；使用该专用组合时不再弹出 Windows 右键菜单，普通右键保持原有行为。
- 设置中的“不透明度”对所有备注卡片生效。分类数据保存在当前用户的本地应用配置中；文件夹被移动后需要重新为新路径添加分类。文件、快捷方式和虚拟项目不显示卡片。
- 关闭主窗口默认收起到托盘；可从托盘暂停/恢复监控或彻底退出。登录 Windows 后会自动在后台恢复监控，这两项可在“设置”关闭。
- 修改选项后必须重新“计算方案”，再点击“应用”。
- “恢复最近备份”可撤销最近一次应用。
- 主窗口、设置窗口和教程窗口会在受支持的 Windows 版本上使用原生圆角，并保留正常的标题栏、缩放与贴靠行为。

## 常见问题

- 双击无反应：安装 x64 `.NET 8 Desktop Runtime`，或重新联网运行安装器。
- 图标未立即刷新：等待 Windows 图标缓存刷新，或重新打开文件夹窗口。
- SmartScreen 警告：当前 Beta 未签名，请从可信发布页下载并核对 SHA-256。
- 软件只替换普通文件夹图标，不替换文件资源管理器本身。
